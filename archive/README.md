# Archive Directory

This directory contains backups and archived files from earlier phases of the project:

- `legacy_vanilla/`: Contains the original pre-migration HTML files (`movies.html`, `tvshows.html`, `index.legacy.html`) and vanilla JavaScript modules (`js/`).
- `react/`: Contains the initial React components from Step 1 before the React Router and MainLayout refactor.
- `AuthModal.jsx`: Archived modal component superseded by the `/login` and `/register` dedicated pages.

These files are preserved for reference and are not active in the production build.
